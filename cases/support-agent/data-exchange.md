# Обмен данными модулей этапа 1

Решено до спецификации. Модули этапа 1: Канал, Разговор, Передача оператору, Системы компании. Все модули в одном приложении (ADR 0005), «вызов» это обращение к контракту модуля, «событие» запись, которую получает подписчик. Источники: `modules.md`, `contracts.md`, `language.md`.

## Что передаётся

**Сообщение клиента** (Канал → Разговор, событие «Клиент написал»): id сообщения, id разговора, договор, адрес, имя, текст, время. Договор, адрес и имя берутся из токена входа, не из текста. Разговор игнорирует сообщение, чей id уже обработан.

**Ответ клиенту** (Разговор → Канал, вызов «Отправить клиенту»): id разговора, текст. Канал отправляет в чат сразу, в этапе 1 других каналов нет.

**Результат проверки аварий** (Системы → Разговор, вызов): одно из «авария действует» (список: id аварии, статус «действует», ожидаемое время или «не указано»), «аварии нет», «авария не проверена». Слова систем уже переведены слоем перевода.

**Пересказ** (Разговор → Передача, часть вызова «Передать»): договор, адрес, тема («интернет», «другая» или «не определена»), последнее сообщение клиента, что проверено (аварии: действует, нет, не проверено), что обещано клиенту (в этапе 1 ничего), время первого сообщения.

**Передача** (Передача оператору владеет): id разговора как ключ, статус «отправляется», «в очереди» (ночью), «принята», «не удалось», пересказ, время. Одна запись на разговор.

**Ответ вызова «Передать»** (Передача → Разговор): «принята», «в очереди» с временем, когда ответит оператор, «не удалось». Повторный вызов того же разговора возвращает существующую запись, а не создаёт новую.

**Событие хелпдеска** (Системы → Передача → Разговор): «оператор взял разговор», «оператор ответил»: id разговора. Передача публикует Разговору «Оператор в разговоре». С этого момента Разговор отвечает клиенту только фразой «оператор ответит».

## Решения о сбоях и повторах

- Передача записывает «отправляется» до вызова хелпдеска. Если ответ потерян, сначала читает статус разговора в хелпдеске, и только если разговор не передан, повторяет через минуту; после двух попыток статус «не удалось».
- Системы аварий не ответили за 10 секунд: «авария не проверена», одна повторная попытка. Разговор не говорит «аварии нет».
- Сообщения клиента, пришедшие во время передачи, не создают второй передачи.
- Расходы: Разговор считает вызовы модели в этом разговоре, лимит 20. Достигнут: фиксированный ответ и «Передать» (одна).
