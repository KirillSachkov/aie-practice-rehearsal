# Язык и границы помощника

Что помощник берёт готовым, в чём его ценность, сколько у него контекстов и где слова систем компании переводятся в слова помощника. Словарь: `GLOSSARY.md`.

## Ценность и готовое (поддомены)

| Часть | Тип | Решение |
| --- | --- | --- |
| Ведение разговора: понять обращение, выбрать следующий шаг, не обещать непроверенного | core | проектируем тщательно, это ценность для компании |
| Передача оператору с пересказом, чтобы не переспрашивали | core | то же |
| Обещание об устранении аварии | supporting | пишем сами, просто |
| Языковая модель | generic | берём готовую по API, свою не обучаем (ADR 0001) |
| Вход в чат, биллинг, сеть, аварии, выезд мастера, хелпдеск, справка, уведомления | generic | системы компании, не меняем |

## Контексты

Один контекст: **Помощник**. Слова «обращение», «разговор», «пересказ», «обещание об устранении», «подтверждение» значат одно и то же везде внутри помощника. Системы компании это чужие модели, у каждой свои слова; на границе с каждой стоит слой перевода (ADR 0002). Отдельных контекстов внутри помощника не делаем: у него один пользователь, один набор правил разговора, и ни один шаг сценария не идёт без вопроса к соседней части.

Проверено сценарием «заявка закрыта, а проблема не решена»: правило «обращение решено» принадлежит помощнику; хелпдеск сообщает только факт «заявка закрыта». У правила один владелец. Проверено сценарием «авария устранена»: система аварий сообщает статус, помощник решает, что обещание выполнено и что сказать клиенту.

Telegram позже это ещё один канал клиента, а не новый контекст. Слова помощника от канала не зависят.

## Спорные слова: два значения

| Слово | В разговоре с клиентом | В системе компании | Решение |
| --- | --- | --- | --- |
| Разговор | цепочка сообщений клиента и помощника | хелпдеск: разговор, который ведёт оператор | один смысл, одно слово. Передача оператору продолжает тот же разговор |
| Обращение | причина написать, в разговоре их может быть несколько | нет | слово помощника. Не путать с заявкой |
| Заявка | нет такого слова для клиента | хелпдеск: консультация, ремонт или выезд для инженеров и диспетчера | в словаре «заявка в хелпдеске». Клиенту говорим «передал инженерам» |
| Авария | «проблема у нас на сети в вашем районе» | действующая авария по адресу со статусом | см. таблицу перевода |
| Визит | «мастер приедет в окно» | запись в выезде мастера | «визит». Просьбу о визите в хелпдеск называем «заявка на выезд» |
| Договор | «ваш договор», номер | номер договора, по нему системы отдают данные | клиент это человек, договор это что видит система |

## Перевод слов систем в слова помощника

| Система | Слово системы | Слово помощника | Что слышит клиент |
| --- | --- | --- | --- |
| Биллинг | активен | договор работает | «Договор в порядке» |
| Биллинг | отключён за неуплату | отключён за неуплату | «Договор отключён: на счёте не хватает денег» |
| Биллинг | добровольная блокировка | заблокирован по просьбе клиента | «Договор заблокирован по вашей просьбе» |
| Аварии | есть действующая авария | авария действует | «По вашему адресу действует авария. Срок: …/пока неизвестен» |
| Аварии | аварии нет | аварии нет | «Аварий по адресу нет» |
| Аварии | запрос не ответил | авария не проверена | «Не могу сейчас проверить аварии» (не «аварии нет») |
| Аварии | авария устранена | авария устранена | «Авария устранена. Если интернета нет, ответьте» |
| Хелпдеск | заявка создана | заявка передана инженерам | «Передал инженерам, ответ придёт в чат» |
| Хелпдеск | заявка закрыта | заявка закрыта, обращение не обязательно решено | «Заявку закрыли. Интернет заработал?» |
| Хелпдеск | оператор взял разговор | оператор в разговоре | «Оператор подключился» |
| Сеть | роутер не в сети / в сети | роутер не виден / виден | «Роутер сейчас не виден в сети» |
| Выезд | визит записан | визит назначен | «Мастер приедет …» |

В файле систем статусы аварии не перечислены. Мы предполагаем три: действует, устранена, неизвестно (запрос не ответил). Если у компании другие статусы, правим только таблицу.

## Открытые вопросы

- Какие статусы реально отдаёт система аварий (если «временно устранена» или «ожидает бригаду»): вопрос к компании.
