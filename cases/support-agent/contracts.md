# Контракты с системами компании

Контракты на языке помощника: слова систем уже переведены (`language.md`). Все восемь систем отдают данные по номеру договора по HTTP и сервисному ключу. Для каждой: что читаем, что делаем, как узнаём о том, о чём она не сообщает, что при сбое, что при повторе.

| Система | Читать | Делать | Узнаём об изменении | Сбой | Повтор |
| --- | --- | --- | --- | --- | --- |
| Вход в чат | договор, имя, адрес | | токен на каждом сообщении | нет токена: писать нельзя | |
| Биллинг | статус договора, баланс, платежи | обещанный платёж, смена тарифа | спрашиваем при разговоре | не ответил: «не могу проверить», действие не делаем, передача оператору | перед повтором читаем состояние: уже ли даны платёж и тариф. Платёж виден через 15 минут |
| Сеть | роутер виден, когда был | перезагрузить | таймер 5 минут после перезагрузки: результат может не прийти | 10 секунд, одна повторная попытка, потом «не могу проверить» | не перезагружать второй раз, пока не известен результат первой |
| Аварии | действующие по адресу, статус, срок | | **только опрос**, раз в 15 минут по адресу (Наблюдение) | не ответил: «авария не проверена», не «аварии нет»; опрос продолжается | повторный запрос безопасен |
| Выезд мастера | окна, визиты договора | записать, перенести, отменить | спрашиваем при разговоре | не ответил: передача оператору | перед записью читаем визиты договора: повтор создаёт второй визит |
| Хелпдеск | статус разговора и заявки | передать разговор, создать заявку | события: оператор взял, оператор ответил, заявка закрыта | не принял: ещё раз через минуту, затем «не удалось», запись остаётся | перед повторной передачей читаем статус разговора: уже передан ли; заявка по ключу «договор + вид + обращение» |
| Справка | статьи, правила (выгрузка Markdown) | | копия обновляется раз в неделю | выгрузки нет: берём прошлую копию | |
| Уведомления | | SMS, push, письмо | | не ответили: сообщение остаётся в исходящих | один исходящий на одно сообщение, ключ в журнале Канала; с 22 до 9 не отправляем; SMS не используем |

## Правила сбоя и повтора

- Помощник никогда не говорит клиенту «сделано» по ответу, которого не получил. Результат неизвестен: говорит «не знаю, проверяю» и проверяет чтением.
- Действие, которое меняет деньги, тариф, визит или роутер, выполняется только с подтверждением и записью в журнал Действий до вызова. Повтор той же записи не вызывает систему второй раз без проверки состояния.
- Передача оператору одна на разговор: запись по id разговора, повтор клиента или повтор шага её не дублирует.
- Об одной аварии пишут сто человек: сто разговоров, сто обещаний, один опрос по адресу. Сообщение об устранении уходит каждому обещанию отдельно, очередью.
- Система не ответила в разговоре: клиенту честно, что не получилось проверить, а затем передача оператору, если без проверки не продолжить.
