# Одну систему компании ведёт один модуль и владеет данными о связи с ней

Каждая система компании (вход и биллинг, аварии, хелпдеск, уведомления) связана ровно с одним модулем помощника, и он один владеет данными об этой связи: записью «платёж запрошен», обещаниями об устранении, записью о передаче, отложенными сообщениями. Остальные модули спрашивают его через контракт. Альтернатива была: общий слой интеграции со всеми системами. Мы её не взяли, потому что он знал бы всё о всех (неглубокий модуль), а повтор и сбой пришлось бы ловить в одном месте для разных правил. Перенос данных из модуля в модуль потом дорог.
