# Слова систем компании переводятся на границе

Правила помощника написаны его словами (авария действует, обращение решено), а статусы систем компании знает только слой перевода на границе с каждой системой. Так смена статусов в системе меняет один слой, а «заявка закрыта» не превращается в «проблема решена». Принять модели систем как есть отвергли: слова разных систем расходятся.
