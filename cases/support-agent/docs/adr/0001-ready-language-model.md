# Языковую модель берём готовую по API

Помощник ведёт разговор готовой языковой моделью через API, свою не обучаем: ценность помощника в правилах разговора и передаче оператору, а не в модели. Поменять поставщика после запуска дорого, потому что вокруг него будут настроены ответы, проверки и расходы, поэтому выбор записан.
