# Об устранении аварии помощник узнаёт опросом по адресу

Система аварий не присылает событий. Модуль «Аварии» опрашивает её раз в 10 минут по адресам с открытыми обещаниями и считает аварию устранённой после двух проверок подряд без неё. Опрос по адресу, а не по клиенту, потому что о той же аварии пишут сотни людей. Обещание об устранении принадлежит «Авариям», а письмо клиенту отправляют «Сообщения клиенту» по событию. Если компания даст события, опрос заменяется, а контракты модулей остаются.
