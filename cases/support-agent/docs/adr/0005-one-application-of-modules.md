# Помощник это одно приложение из модулей с одной базой

Помощник запускается одним приложением из пяти модулей (`modules.md`); опрос аварий и отправка отложенных сообщений работают фоновыми задачами в нём же. Данные лежат в одной реляционной базе с транзакциями, у каждого модуля свои таблицы. Причина: у модулей нет ни отдельной нагрузки, ни отдельной команды, ни отдельных чувствительных данных, а запись об обещании или о передаче должна сохраняться в одной транзакции с изменением. Отвергнуты: сервис на каждый модуль (сеть и деплой раньше, чем нужны); сервис «Аварии» отдельно (причины нет, пока опрос не мешает чату). Конкретную базу и язык выбирает реализация. Модуль можно вынести позже, потому что модули общаются через контракты.
