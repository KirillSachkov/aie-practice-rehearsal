# Данные клиента не копируем, владельцы данных помощника

Тариф, баланс, статус договора, платежи, роутер и визиты остаются у систем компании, помощник спрашивает каждый раз. Свои данные у каждого модуля одни владельцы: разговор, передача, обещание, исходящее сообщение, журнал действий. Копии допустимы только для справки. Если ошибиться, данные придётся переносить, а соседним модулям менять запросы.
