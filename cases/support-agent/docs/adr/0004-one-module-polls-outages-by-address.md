# Опрос аварий ведёт один модуль, по адресу

Система аварий не присылает события, поэтому модуль «Наблюдение за авариями» опрашивает её раз в 15 минут по адресу, а не по обещанию. Остальные модули получают его событие «Авария устранена». Иначе при аварии на сотни клиентов запросов будет в сотни раз больше, а модули разойдутся в статусе.
